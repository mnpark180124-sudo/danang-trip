DANANG TRIP V3-1 적용 순서

1. Supabase Dashboard → Authentication → Providers에서 Anonymous Sign-Ins를 활성화합니다.
2. SQL Editor → New query → v3-1-setup.sql 전체 붙여넣기 → Run.
3. GitHub 저장소에서 V3-1 파일을 덮어씁니다.
4. GitHub Pages 배포 완료 후 메인 화면에서 '함께 쓰는 여행방'을 확인합니다.
5. 내 닉네임을 입력하고 '새 여행방 만들기'를 누릅니다.
6. 표시된 여행방 코드를 다른 휴대폰에 입력하고 같은 화면에서 닉네임과 함께 '참여'를 누릅니다.
7. 양쪽에서 참여자 목록이 보이면 V3-1 성공입니다.

중요:
- Supabase Publishable key는 웹앱에서 사용하는 공개용 키입니다.
- service_role / secret key / DB 비밀번호는 GitHub나 채팅에 올리지 마세요.
- V3-1은 여행방/참여자만 추가하며 기존 환율·날씨·지도·맛집 기능은 유지합니다.
